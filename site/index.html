What it does

Every agent, side by side

Claude Code, Codex, Gemini CLI, Copilot, OpenCode and more, each in its own folder and git branch, grouped in spaces.

Who needs you

Working, finished or waiting on you, at a glance. Questions show up as cards you answer in one click.

Review and ship

See what each agent changed, comment on any line, then commit, push and open a pull request from the same place.

On your phone, free

Pair your phone with a free Cloudflare account or Tailscale. End-to-end encrypted, with a ping when an agent needs you.

A chief of staff

Say what you need in plain words. It hands the work to the right agent and tells you when it's done.

Cloud agents too

Start Cursor, Copilot, Jules and Claude agents in their clouds with your own keys, next to the ones on your computer.

Install

macOS, Linuxcurl -fsSL https://raw.githubusercontent.com/sahil1/bridge/main/install.sh | sh
Windowsirm https://raw.githubusercontent.com/sahil1/bridge/main/install.ps1 | iex

Paste it in Terminal (or PowerShell on Windows). It downloads the app, installs it and opens it. Run it again to update.

Downloaded the Mac app instead? It isn't signed by Apple yet, so macOS asks before the first open: click Done, then System Settings › Privacy & Security › Open Anyway. The command above skips that step. On Windows, SmartScreen may ask first: More info › Run anyway.

Mac, Apple Silicon (.dmg) Mac, Intel (.dmg) Windows (.exe) Linux (.AppImage) Debian, Ubuntu (.deb)

Yours, on your machine

Bridge AI runs on your computer. Your agents use their own sign-ins, and the project collects nothing about you: no account, no analytics, no ads. The code is all on GitHub if you'd rather read it first or run it yourself.
